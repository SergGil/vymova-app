Privacy Policy

Last updated: July 2026

Vymova is a vocabulary trainer (flashcards, spaced repetition, practice games, and an optional AI tutor). This page explains what data the app handles, where it goes, and how you can remove it. It applies to the app at whatever address you're reading this from.

What stays on your device

By default, everything Vymova tracks about your learning is stored only in your browser's local storage — nothing is sent anywhere. This includes:

  • Which words you know, your spaced-repetition (SRS) schedule, and mistake history
  • Achievements, streaks, XP, and daily goals
  • App settings — theme, font size, chosen language pair, notes, bookmarks

Uninstalling the app, clearing your browser's site data, or using a private/incognito window removes all of it. Nothing here ever leaves your device unless you turn on cloud sync (below).

Optional cloud sync

If you turn on sync (Settings → Cloud Sync), the data listed above is uploaded to a Firebase Realtime Database (hosted in the EU, europe-west1) so you can restore it on another device.

  • No account, email, or name is required. Sync is identified only by a short random code generated on your device — you choose whether to share that code with yourself on another device.
  • Turning sync off, or simply not using it, means nothing is uploaded.
  • To have synced data deleted, email us the sync code (see Contact below) — we can't find or delete it without that code, since we don't store anything that links a code to a person.

AI features (AI Tutor, voice roleplay, generated stories)

These are optional and off by default. When you use one, the message or sentence you type is sent to Vymova's own backend proxy, which forwards it to Google's Gemini API to generate a reply. That input is processed under Google's own privacy policy — Vymova does not store the conversation itself beyond your current session. If the AI backend isn't available, these features are simply hidden, or (for stories) fall back to built-in offline text.

Usage analytics

Some deployments of this app (including the one at serggil.github.io/vymova-app) have Firebase Analytics — built on Google Analytics — turned on to understand how the app is used. If it's active on the deployment you're using, it automatically collects:

  • Usage events (e.g. app opened, a practice mode started), approximate location (derived from IP, not stored precisely), device/browser type, and a Google-generated analytics identifier

This data goes to Google and is processed under Google's privacy policy; Vymova doesn't combine it with your learning progress, sync code, or any other data described on this page. It is not currently gated behind a cookie/consent prompt — if you'd rather it not run, a browser extension like Google's own Analytics opt-out add-on, or a content/tracker blocker, will stop it. A self-hosted fork of this open-source app may have analytics off entirely, depending on how its owner configured it.

Duels and leaderboards

Real-time duels and leaderboard rankings use the same database as cloud sync. The display name you choose in-app is visible to your opponent and on the leaderboard — use a nickname rather than your real name if you'd rather not share it.

Optional third-party API key (images)

If you add your own Pixabay API key (Settings) to enable word illustration images, that key is stored the same way as other settings (locally, and synced if sync is on) and is only ever used to call Pixabay's API directly from your browser.

What Vymova does not do

  • No ads, no ad networks, no ad-tracking pixels
  • No analytics beyond the Google Analytics usage described above — no other usage-tracking scripts
  • No cookies used for tracking beyond what Google Analytics itself sets (see above); everything else is browser local storage, described earlier on this page
  • No selling of data with third parties, and no sharing beyond what's described above

If any of this changes in the future, this page will be updated accordingly before the change ships.

Children

Vymova isn't directed at children under 13, and we don't knowingly collect any personal information from them. Sync, when enabled, only ever stores anonymous learning progress under a random code, never a name, birthdate, or contact detail.
